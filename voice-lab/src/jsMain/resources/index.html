GATE 3A

한국어 SentencePiece 토큰화

MOSS의 약 471 KB `tokenizer.model`과 공식 Reader가 사용하는 브라우저 SentencePiece 구현을 연결해 실제 한국어 문장이 토큰 ID로 변환되는지 검증합니다. 이 단계는 음질 판정이 아닙니다.

한국어 테스트 문장하나님은 너를 정말 사랑하신단다.
대기

모델 세션과 독립적으로 실행할 수 있습니다.

Gate 3A가 통과하면 global decode-step을 같은 INT8 shared weight에 연결하고, builtin voice prompt와 함께 첫 실제 한국어 WAV 합성으로 넘어갑니다. Production TTS는 모바일 안정성·한국어 음질 Gate가 끝날 때까지 변경하지 않습니다.
